# Lend your GPU: contributing generated assets

The game's scenery is made by local AI models: a text prompt becomes a picture, the picture becomes a 3D model. That work
needs a strong graphics card and time, not programming. If you have the hardware, you can generate models, images or
sounds on your own computer and send them in. No code required.

## What is wanted

- **First:** the gaps listed under "Gaps worth generating next" in [GENERATED_ASSETS.md](GENERATED_ASSETS.md) — it has
  ready-to-use prompts. Characters, enemies and animals are the biggest gap; then interiors and modular building pieces.
- **Also:** anything an accepted idea needs (see the most-voted posts in
  [Discussions → Ideas](https://github.com/TengilOurLiberator/omnissiah/discussions/categories/ideas) and the matching task in [IMPROVEMENTS.md](IMPROVEMENTS.md)).
- **Style:** one object per model, stylised, chunky, hand-painted look, warm palette, like the existing set. Look at a few
  pictures in `public/assets/generated/startzone/*.png` first. Photoreal scans, logos, text, real people and characters from
  other games, films or comics are not accepted.

## How to make them

Use any generator you can run **locally**. The project's own pipeline is in the repository:

- `server/gen3d/` — text → image (Z-Image-Turbo) → 3D model (TRELLIS), plus optional rigging. It was set up by hand in WSL2 on an NVIDIA card; expect to adapt it.
- `tools/startzone-batch/run.mjs` — an unattended batch runner: give it a list of `{ id, prompt, size_m }` and leave it overnight.
  It checks GPU temperature and memory before each job and stops on repeated failures.
- `tools/startzone-batch/optimize.mjs` — makes the light "Quest twin" of each model with headless Blender.

Other tools are fine too (a different image-to-3D model, or modelling by hand in Blender), as long as the result meets the format below
and you may legally give it away. Check the licence of the generator you use: some forbid redistribution or exclude certain countries.

The shared style line used for the existing set: `hand-painted low-poly fantasy, chunky shapes, warm dusk palette`.
Prompts work best as: one object, whole object in frame, plain background, nothing thin or transparent.

## Format

Put each asset in its own folder: `public/assets/community/<id>/` where `<id>` is short, lowercase, with dashes (e.g. `fox-sitting`).

| File | What |
|---|---|
| `model.glb` | the model: one object, ≤ 20,000 triangles, ≤ 1.5 MB, textures embedded; scaled so the longest side is 1 unit, base at y = 0, centred |
| `q.glb` | the light twin for standalone headsets: ≤ 2,500 triangles, texture ≤ 512 px (characters: ≤ 4,000) |
| `source.png` | the picture the model was made from, or a clear render of it (≤ 1024 px). The reviewer judges the asset from this, so it must show the real thing |
| `meta.json` | see below |

```json
{
  "id": "fox-sitting",
  "name": "Sitting fox",
  "group": "animals",
  "tags": ["fox", "animal", "forest"],
  "size_m": 0.7,
  "ground": true,
  "solid": false,
  "prompt": "a red fox sitting, ...",
  "generator": "Z-Image-Turbo + TRELLIS",
  "rigged": false,
  "author": "your GitHub name",
  "licence": "Public domain (Unlicense), generated by me"
}
```

`size_m` is how long the longest side should be in the game, in metres. For rigged characters add `"rigged": true`, the clip
names in `"clips"`, and keep the skeleton and animations inside `model.glb`.

Images (icons, cards, portraits) and sounds follow the same idea: one folder, the file, a `meta.json` with `id`, `name`,
`kind` (`icon` | `card` | `portrait` | `sfx` | `music`), `prompt`, `generator`, `author`, `licence`.

## Sending them

1. Fork the repository, add your folders under `public/assets/community/`, and open a pull request. Up to about 30 assets or 40 MB per pull request.
2. In the description say what you generated, with which tools, and for which task or idea.
3. The pull request is reviewed like any other ([HOW_TO_HELP.md](HOW_TO_HELP.md)): the reviewer looks at every `source.png`,
   checks sizes and `meta.json`, and approves the set or asks for specific ones to be redone or removed.
4. After merging, the maintainer adds the accepted assets to the in-game library (`world.gen`), so the game and the
   in-game AI can use them.

By contributing you release the assets into the public domain like the rest of the project ([LICENSE](../LICENSE)).
